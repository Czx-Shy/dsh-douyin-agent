# 1.4.12 本地更新（未发布）

包含用户主页、主动私信、评论读取与回复，以及本轮评审发现问题的修复。

## 新功能

- **用户搜索 / 主页**：`douyin_search_user` 返回可见用户列表（昵称、抖音号、粉丝数、是否已关注）；`douyin_open_user` 打开主页并返回资料与作品列表，已从主页弹层状态返回时优先按 Esc 收起弹层。主页资料在首屏渲染完成后才返回，`worksTruncated` 标明作品列表是否被截断。
- **主动私信**：`douyin_message_user` 按 secUid 或主页链接进入作者主页发送一条纯文字私信。独立开关、每日上限、最小发送间隔、24 小时未决收据拦截；关注受限账号按 `autoFollow` 决定是否先关注再发送；发送后回读会话核对，结果不明保留收据且不自动重发。设置页“主动私信”分类与 `/outbound/configure` 对应，独立软件另有 `/api/outbound/state|configure`。
- **自主观看进主页**：观看决策新增 `open_author`。宿主读取当前作品作者主页后做第二轮判断（`open_work` / `message_author` / `leave` / `stop`），再回到观看循环。主页次数独立计账（“查看主页”分类、`/profile-view/configure`）；同一次运行内连续访问同一作者最多 5 次且不重复扣次数。
- **评论读取与回复**：`douyin_read_comments` 只读当前作品可见评论（不受“允许观看”时段限制）；自主评论可用 `replyToIndex` 回复已有评论。

## 修复

- 主动私信结束后自动收起私信弹窗（Esc，失败时回到作者主页），避免后续自主观看被判为“页面需要手动处理”；私信与观看/回复共用同一把跨进程页面锁，并在发送前建立页面连接。
- 关注提示改用正则匹配（原 `text=A,text=B` 写法在 Playwright 中永远匹配不到），并把关注判断提前到“对话框必须已打开”之前，`autoFollow` 真正生效。
- 回复序号与读取口径一致：只按顶层评论计数，楼中楼不占位，点击目标用一次性标记定位。
- `douyin_open_user` 等待主页加载完成再返回；搜索页不再把用户卡片和相关搜索区块当视频结果；主页统计按资料区最短文本取值，关注数可解析万/亿。
- 图文作品补标题（退回页面标题）与作者；标题去掉“展开相关搜索/合集、识别画面”等界面尾巴。
- 私信收据不再落盘正文预览，只保留字数与 SHA-256；人格卡“最近的抖音作品观察”按作品去重。
- 空闲时停止私信自动回复不再追加 `service.stopped` 事件。
- `douyin_chat_start` 使用宿主模型启动；未选择模型时提示在设置页选择，而不是报“没有找到 DeepSeek API Key”。

## 验证边界

本轮修复的解析与序号逻辑有合成页回归；主动私信的真实发送与关注流程仍受账号风控和页面结构影响，未在关注受限账号上复测。公开评论发布、音频后端、群视频队列不在本次改动范围。
